# vep-link v0.3 — Result-Fidelity & Token/Observability Polish Design

**Date:** 2026-06-17
**Status:** Approved (full scope; clean-break schema → 0.3.0)
**Supersedes/extends:** `2026-06-17-vep-link-v0.2-hardening-design.md`

## Problem

A second LLM-consumer test pass (all 7 tools, 19+ live calls) against the **v0.2
instance** — confirmed live by hoisted `position_scores`, populated
`warnings[]`, liftover REF validation, and non-zero `elapsed_ms` — surfaced four
issues that v0.2 did not address (and in one case mis-diagnosed). The infra and
facade remain ~9/10; these are the functional-fidelity and token/observability
gaps that keep the data path from being defensibly *beyond* 9/10.

### Findings (source-verified)

1. **Representative transcript is not consequence-aware (correctness).**
   `extraction.prioritize_transcript()` (`extraction.py:146`) ranks
   `pick=1 > MANE > canonical > first` with **no regard for the variant's
   consequence on that transcript**. `build_annotation` takes top-level
   `gene_symbol` from that pick (`extraction.py:226`), while
   `most_severe_consequence` comes straight off the raw VEP record
   (`extraction.py:237`). On a contiguous-gene locus the two disagree: a query
   for PKD1 `NM_001009944.3:c.11935C>T` returns `most_severe_consequence:
   stop_gained` but `gene_symbol: TSC2` with a TSC2 `downstream_gene_variant`
   as the compact `representative_transcript`. Same heuristic feeds compact mode
   via `shaping.pick_representative_transcript` (`shaping.py:103,162`).

2. **recode_variant does not echo the caller's input (contract).**
   `aggregate_recode_entry()` sets `{"input": entry.get("input"), "id":
   entry.get("id")}` (`_recoding.py:83`), reading from the Ensembl Variant
   Recoder POST entry — which comes back **null** at runtime (observed:
   `"input":null,"id":null` on every result). The batch annotator, by contrast,
   threads the original string back (`vep_service.py:~341`,
   `results.append({**annotation, "input": original})`). With a 200-item recode
   batch the caller cannot map results to inputs. *Note: the v0.2 spec recorded
   this as "already echoes input/id (`_recoding.py:69`)"; that is incorrect —
   it echoes the upstream entry, not the caller's input.*

3. **recode_variant `fields` filter leaks unrequested fields (token waste).**
   `fields` is forwarded upstream (`ensembl_client.py:110`,
   `recoder_post(..., fields=...)`) but the shaped output is assembled by
   iterating a hardcoded tuple `_RECODE_FIELDS = (vcf_string, hgvsg, hgvsc,
   hgvsp, spdi)` (`_recoding.py:23`) with **no client-side projection**.
   Observed: requesting `fields=hgvsg,spdi,vcf_string` still returned `hgvsc`
   and `hgvsp`. The documented "trim the payload" promise does not hold when
   Ensembl ignores or partially honors the param.

4. **No isoform collapsing in `standard` (token waste).**
   `_select_transcripts()` (`shaping.py:170`) filters uninformative neighbours,
   sorts by impact, and caps — but never collapses transcripts with an
   **identical effect**. Observed: COL4A5 `c.1871G>A` returned ~8 rows all
   carrying the identical `p.Gly624Asp` + SIFT/REVEL/AlphaMissense values.

5. **Cache hits are indistinguishable from a broken timer (observability).**
   The `run_mcp_tool` timer correctly wraps the full body
   (`errors.py:291`→`_stamp_elapsed`, `errors.py:226`); the observed
   `elapsed_ms: 0` is an `alru_cache` hit (`vep_service.py:114`, TTL 86400 s)
   returning instantly. A consumer has no signal to tell "instant cache hit"
   from "timer bug" from "slow cold path" (the HGVS cold path was ~20 s).

## Locked decisions

- **Scope:** all four areas — representative-transcript correctness, recode
  fidelity (input echo + `fields`), isoform collapsing, cache/latency telemetry.
- **Compatibility:** clean break. Bump `__version__` and `CAPABILITIES_VERSION`
  to a `0.3.0` line; document the schema diff in `get_capabilities`. No legacy
  response shape retained, no shim.
- **`gene_symbol` ⟂ `most_severe_consequence` must agree** at the variant level
  for every annotation tier above `minimal`.
- **Collapsing is loss-free:** only transcripts with a byte-identical effect
  signature merge; `transcripts="all"` always bypasses it.
- **Telemetry is additive to `_meta.timing`,** never replaces `elapsed_ms`.

## Cross-cutting contracts (clean break → 0.3.0)

### Consequence-anchored representative (resolve_variant, annotate_variant)
For any variant entry, the top-level `gene_symbol` and the compact
`representative_transcript` are chosen from the set of transcripts that carry
`most_severe_consequence`. Guarantee: a returned `gene_symbol` always names a
gene on which the reported `most_severe_consequence` occurs.

### `_meta.timing` (all tools)
```jsonc
"timing": { "elapsed_ms": 21,        // total tool wall-time (unchanged)
            "upstream_ms": 0,        // NEW: Ensembl wall-time this call
            "cache_hit": true }      // NEW: served from alru_cache
```
- Cold network call: `cache_hit:false`, `upstream_ms ≈ elapsed_ms`.
- Cache hit: `cache_hit:true`, `upstream_ms:0`, `elapsed_ms` tiny.
- Pure-local rejection (e.g. same-assembly liftover): `cache_hit:false`,
  `upstream_ms:0`.

### Collapsed transcripts (`standard` tier)
```jsonc
"transcript_consequences": [
  { "gene_symbol":"COL4A5","transcript_id":"ENST00000328300","impact":"MODERATE",
    "consequence_terms":["missense_variant"],"hgvsp":"...p.Gly624Asp",
    "revel":0.91,"am_pathogenicity":0.4398,"am_class":"ambiguous",
    "equivalent_transcript_ids":["ENST00000361603","ENST00000949141", "..."] }
],
"transcripts_summary": { "shown": 2, "collapsed": 6, "total": 11 }
```
- The shown member is the MANE/canonical transcript of the identical-effect
  group (falling back to first). `equivalent_transcript_ids` lists the merged
  isoforms; omitted when a row is unique.
- `transcripts_summary` gains a `collapsed` count; `shown` + `collapsed` reflect
  the post-collapse view. Key retained, not promoted to a warning.

### recode_variant result (cap 200)
```jsonc
{ "input":"NM_001009944.3:c.11935C>T", "id":"rs...|null",
  "hgvsg":[...], "spdi":[...] }          // only the requested `fields` keys
```
- `input` is the caller's original string (positional thread), never null.
- With an explicit `fields` filter, only those representation keys appear.

## Design by area

### A. Consequence-anchored representative transcript (Finding 1)
- Add `select_representative(transcripts, most_severe_consequence)` to
  `extraction.py`: (1) filter to transcripts whose `consequence_terms` include
  `most_severe_consequence`; (2) within that subset reuse the existing
  `pick=1 > MANE > canonical > first` ordering (extract the inner ranking from
  `prioritize_transcript` into a private `_rank_biological(transcripts)` helper
  so both call sites stay DRY); (3) fall back to `_rank_biological(all)` when the
  subset is empty (e.g. a record with no `most_severe_consequence`).
- `build_annotation` derives `gene_symbol` from `select_representative(...)`
  (`extraction.py:226`).
- `shaping._compact` calls `select_representative` instead of
  `pick_representative_transcript`; the old `pick_representative_transcript`
  becomes a thin wrapper (or is removed — clean break) so `shaping.py` and
  `extraction.py` share one selection path.
- **Stretch (optional, behind a follow-up):** when the input was a transcript
  HGVS, prefer that transcript id within the subset. Requires threading the
  parsed input transcript into `build_annotation`; deferred unless cheap.

### B. recode input echo (Finding 2)
- `_recode_impl` (`vep_service.py:369`) receives the ordered `variants` tuple
  already. Zip the caller's inputs onto the recoder entries positionally
  (Variant Recoder POST preserves request order) and pass each `input` into
  `aggregate_recode_entry(entry, input=...)`, which sets `result["input"]` from
  the caller value rather than `entry.get("input")`. Keep `id` from the entry
  when present, else null.
- Guard: if upstream returns a different count than requested, fall back to
  `entry.get("input")` and emit nothing misleading (defensive; document).

### C. recode `fields` projection (Finding 3)
- After aggregation, apply a client-side projection keyed by the requested
  `fields` (parse the comma list once in `_recode_impl`). Keep forwarding
  `fields` upstream for bandwidth. When `fields is None`, return the full
  documented set. Implement as a small pure helper
  `project_recode_fields(result, fields)` in `_recoding.py`; omit unrequested
  keys entirely (no empty-list keys).

### D. Isoform collapsing (Finding 4)
- Add a pure `collapse_identical(rows)` to `shaping.py`: group projected rows by
  an effect signature `(tuple(consequence_terms), hgvsp, impact,
  sift_prediction, polyphen_prediction, revel, am_pathogenicity, am_class)`;
  for each group keep the MANE/canonical member (else first) and attach
  `equivalent_transcript_ids` for the rest (omit when singleton). Preserve
  most-severe ordering. Wire into `_select_transcripts` for `transcripts="auto"`
  only; `"all"` bypasses. Return `(rows, shown, collapsed, total)` and extend
  `transcripts_summary` accordingly.

### E. Cache + upstream telemetry (Finding 5)
- Two request-scoped `ContextVar`s, reset at the start of `run_mcp_tool`
  (`errors.py:276`): `cache_hit` (default `False`) and `upstream_ms` (default
  `0`). ContextVars are copied per async task, so concurrent requests under the
  semaphore do not clobber each other.
- **Deterministic hit/miss, no racy `cache_info()` diff:** wrap each
  `alru_cache`-backed impl (`vep_service.py:114-116`) so the wrapper sets
  `cache_hit=True` immediately before delegating to the cache lookup, and the
  **inner** impl flips it back to `False` the moment it actually executes (a
  miss). A value served from cache skips the inner body, so the flag stays
  `True`; a miss ends at `False`. Correct because `alru_cache` awaits the inner
  coroutine in the caller's context (no `create_task`), so the `set` propagates.
  Tools that never enter a cached wrapper (liftover, health) keep the `False`
  default — accurate, since nothing was cached.
- Accumulate Ensembl wall-time into `upstream_ms` in the HTTP layer
  (`base_client` around each `request`/retry attempt), so it reflects real
  upstream time including retries.
- `build_meta` (`resources.py:246`) reads the two ContextVars and adds
  `upstream_ms` and `cache_hit` under `timing` alongside `elapsed_ms`.

## Config additions (`VEP_LINK_` prefix)
- `COLLAPSE_IDENTICAL_TRANSCRIPTS=true` — opt-out switch for area D.
- `TIMING_TELEMETRY=true` — gate the new `_meta.timing` fields (area E).
All overridable; defaults chosen for correctness/transparency.

## File-size & structure
Current LOC: `vep_service.py` 439, `errors.py` 397, `shaping.py` 237,
`extraction.py` 243, `_recoding.py` 85, `resources.py` 296, `base_client.py`
284. Area B/C/E touch `vep_service.py`; if it crosses ~500 LOC, split recode
orchestration into `services/recode_service.py` (cohesive split per the 600-LOC
discipline). Areas A and D land in `extraction.py`/`shaping.py` (ample room).
ContextVar plumbing is a few lines each in `base_client.py`, `errors.py`,
`resources.py`. No file is projected to breach the cap.

## Testing (zero real network; respx-mocked)
New/updated unit tests:
- **Contiguous-locus fixture** (PKD1/TSC2-style record where the canonical
  transcript is a neighbour-gene MODIFIER and the most-severe is on the queried
  gene): assert `gene_symbol` names the most-severe gene and
  `representative_transcript.consequence_terms` includes
  `most_severe_consequence`, in both compact and minimal.
- **recode echo**: multi-input recoder fixture; assert each result `input`
  equals the caller string and order is preserved.
- **recode `fields`**: assert an explicit `fields` filter yields only those keys
  and `fields=None` yields the full set.
- **isoform collapse**: multi-isoform identical-effect fixture; assert one shown
  row + `equivalent_transcript_ids`, `transcripts_summary.collapsed` count, and
  that `transcripts="all"` returns every row uncollapsed.
- **telemetry**: cache-miss → `cache_hit:false`, `upstream_ms>0`; immediate
  re-call → `cache_hit:true`, `upstream_ms:0`; same-assembly liftover →
  `cache_hit:false`, `upstream_ms:0`.
- **runtime-parity guard** (integration-marked) extended to assert the new
  `_meta.timing` keys exist.

`make ci-local` (ruff + lint-loc + mypy + 80% coverage) is the gate. Live
behaviors stay behind `integration` marks; the `tests/conftest.py` no-network
guard remains in force.

## Non-goals
- The ~20 s cold HGVS path is upstream-bound (Variant Recoder + VEP). The
  existing alru cache mitigates repeats; the new `upstream_ms`/`cache_hit` make
  it *visible*. No code-level latency fix here.
- No new tools, no build auto-routing, no per-type VEP GET endpoints.
- Input-transcript-aware representative selection is a documented stretch item,
  not committed scope.
