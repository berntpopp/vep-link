# vep-link Implementation Plan

> Historical record — this document records the original implementation plan.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `vep-link`, a unified REST + MCP server wrapping Ensembl VEP and Variant Recoder across GRCh38 (`rest.ensembl.org`) and GRCh37 (`grch37.rest.ensembl.org`).

**Architecture:** MCP-first. FastAPI host = `/health` + mounted MCP at `/mcp`. Every input is normalized to canonical `CHR-POS-REF-ALT` (via Variant Recoder for rsID/HGVS/SPDI; directly for VCF/CNV) then batched through VEP `region` POST. Six MCP tools + structured error/`_meta` envelopes mirroring the existing fleet (`gnomad-link`, `litvar-link`, `spliceailookup-link`).

**Tech Stack:** uv + hatchling, py≥3.12; FastAPI/uvicorn/gunicorn; FastMCP + mcp[cli]; httpx + async-lru; pydantic v2 + pydantic-settings; structlog + asgi-correlation-id + prometheus-client + orjson; typer + rich. Dev: pytest(+asyncio/cov/mock/xdist), respx, ruff, mypy, pre-commit.

**Reference implementations to mirror (read these):**
- `../gnomad-link` — pyproject, mcp/errors, mcp/facade, mcp/resources, logging_config, server_manager, cli, Dockerfile, Makefile, pre-commit, scripts/check_file_size.py.
- `../spliceailookup-link` — `variant.py` (parser), `api/base_client.py`, `api/ensembl_client.py`, `config.py` (GenomeBuild Literal, build URL selection), 4-tier response_mode shaping, `mcp/annotations.py`, `mcp/errors.py` structured envelope, `mcp/tools/*`.
- `../variant-linker` — proven Ensembl request/response shapes (cloned at `../variant-linker`; see `config/apiConfig.json`, `src/variantLinkerCore.js`, `src/variantRecoderPost.js`, `src/vepRegionsAnnotation.js`, `src/dataExtractor.js`, `test/helpers.js`).

## Locked shared contracts (all tasks MUST conform)

### Enums (`vep_link/models/enums.py`)
```python
from enum import Enum

class GenomeBuild(str, Enum):
    GRCH38 = "GRCh38"
    GRCH37 = "GRCh37"

class ResponseMode(str, Enum):
    MINIMAL = "minimal"
    COMPACT = "compact"
    STANDARD = "standard"
    FULL = "full"

class InputKind(str, Enum):
    COORDINATE = "coordinate"  # CHR-POS-REF-ALT (a.k.a. VCF 4-token)
    CNV = "cnv"                # chr:start-end:TYPE
    HGVS = "hgvs"              # g./c./n./p. notation
    RSID = "rsid"              # rs\d+
```
`GenomeBuild` values are the assembly strings used everywhere. Literal type alias for tool args: `Literal["GRCh38", "GRCh37"]`.

### Error codes (`vep_link/mcp/errors.py`)
`invalid_input, unsupported_input, not_found, build_mismatch, ambiguous, rate_limited, upstream_unavailable, upstream_timeout, output_validation_failed, internal_error`.

Error envelope shape (returned by `run_mcp_tool` on failure):
```python
{
  "error": {
    "code": <error_code>,
    "message": <str>,
    "recovery": <str>,
    "fallback_tool": "get_capabilities",
    "next_commands": [{"tool": <str>, "arguments": {...}}],
  },
  "_meta": { ... standard _meta ... },
}
```

### Exceptions (`vep_link/exceptions.py`)
```python
class VepLinkError(Exception): ...
class ConfigurationError(VepLinkError): ...
class VariantParseError(VepLinkError): ...            # -> invalid_input
class UnsupportedContigError(VariantParseError): ...   # -> unsupported_input
class UpstreamInputError(VepLinkError): ...            # 4xx from Ensembl -> not_found/invalid_input
class RateLimitedError(VepLinkError): ...              # 429 / saturated -> rate_limited
class UpstreamTimeoutError(VepLinkError): ...          # -> upstream_timeout
class EnsemblApiError(VepLinkError): ...               # 5xx / transport -> upstream_unavailable
class DataNotFoundError(VepLinkError): ...             # -> not_found
class AmbiguousMappingError(VepLinkError): ...         # -> ambiguous
```

### `variant.py` interface
```python
@dataclass(frozen=True)
class VariantInput:
    kind: InputKind
    value: str   # canonical: coordinate -> "CHR-POS-REF-ALT"; cnv -> "CHR:START-END:TYPE"; hgvs/rsid -> cleaned input

def parse_variant_input(text: str) -> VariantInput: ...   # raises VariantParseError / UnsupportedContigError
def clean_hgvs(text: str) -> str: ...                      # strip (p.…)/(gene) annotations
def coordinate_to_vep_line(coord: str) -> str: ...         # "1-65568-A-C" -> "1 65568 . A C . . ."
def cnv_to_vep_line(cnv: str) -> str: ...                  # "7:100-200:DEL" -> "7 100 200 deletion 1"
def needs_recoding(vi: VariantInput) -> bool: ...          # True for HGVS/RSID, False for COORDINATE/CNV
```
Detection order: rsID (`^rs\d+$`) → 4-token coordinate (`[\s:\-]` split, strip `chr`, chroms `1-22,X,Y,M,MT`) → CNV (`^[0-9XYM]+:\d+-\d+:(DEL|DUP|CNV|INS|INV|CUSTOM)$`) → else HGVS. MT contig in a liftover context raises `UnsupportedContigError` (handled in the liftover tool, not the parser).

### `api/ensembl_client.py` interface (async, build-aware)
```python
class EnsemblClient:
    def __init__(self, settings: Settings) -> None: ...
    async def aclose(self) -> None: ...
    async def recoder_get(self, variant: str, build: GenomeBuild, *, fields: str = "vcf_string") -> dict: ...
    async def recoder_post(self, ids: list[str], build: GenomeBuild, *, fields: str = "vcf_string") -> list[dict]: ...
    async def vep_region_post(self, lines: list[str], build: GenomeBuild, *, options: dict[str, str]) -> list[dict]: ...
    async def vep_hgvs_get(self, hgvs: str, build: GenomeBuild, *, options: dict[str, str]) -> list[dict]: ...
    async def vep_id_get(self, rsid: str, build: GenomeBuild, *, options: dict[str, str]) -> list[dict]: ...
    async def assembly_map(self, region: str, from_build: GenomeBuild, to_build: GenomeBuild) -> dict: ...
```
- Recoder POST body `{"ids": [...]}`, query `{"vcf_string": "1", ...}`. POST path `/variant_recoder/homo_sapiens`; GET path `/variant_recoder/human/{id}`.
- VEP region POST body `{"variants": [...]}`, path `/vep/homo_sapiens/region`.
- Chunk POST inputs at `settings.CHUNK_SIZE` (200) with `INTER_CHUNK_DELAY_MS` between chunks; aggregate results.
- All requests go through `base_client` (retry/backoff/Retry-After/semaphore).

### `services/vep_service.py` interface
```python
class VepService:
    def __init__(self, client: EnsemblClient, settings: Settings) -> None: ...
    async def resolve(self, variant: str, build: GenomeBuild) -> dict: ...
    async def annotate(self, variant: str, build: GenomeBuild, *, vep_options: dict|None) -> dict: ...
    async def annotate_batch(self, variants: list[str], build: GenomeBuild, *, vep_options: dict|None) -> dict: ...
    async def recode(self, variants: list[str], build: GenomeBuild, *, fields: str|None) -> list[dict]: ...
    async def liftover(self, variant: str, from_build: GenomeBuild, to_build: GenomeBuild) -> dict: ...
```
Service methods return **plain dicts of extracted/normalized data** (not yet response-mode-shaped); the MCP tool layer applies `shaping`. `annotate_batch` returns `{"results": [...], "errors": [{"input":..., "error_code":..., "message":...}], "summary": {...}}`.

### `_meta` builder (`vep_link/mcp/resources.py` or `_meta.py`)
```python
def build_meta(*, tool: str, request_id: str, elapsed_ms: int, assembly: str|None = None,
               next_commands: list|None = None, extra: dict|None = None) -> dict:
    return {
        "tool": tool, "request_id": request_id,
        "timing": {"elapsed_ms": elapsed_ms},
        "capabilities_version": CAPABILITIES_VERSION,
        "unsafe_for_clinical_use": True,
        "next_commands": next_commands or [],
        "assembly": assembly,
        **(extra or {}),
    }
```
